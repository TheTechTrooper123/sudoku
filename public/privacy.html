B. das Überschreiten des Rate-Limits) werden zur Nachverfolgung kurzzeitig in den Server-Logs des Hosters protokolliert; die betroffene IP kann zum dauerhaften Sperren missbräuchlicher Quellen verwendet werden.

Privacy policy

This website is a Sudoku game. You can use it completely without an account, without cookies and without advertising.

1. Controller

The controller for this website is the private operator of this offer (a non-commercial project). Because no personal data is collected, stored or processed, no contact details are provided.

2. What data is processed

  • No local storage: the game state, notes, statistics and settings are not stored. No localStorage and no cookies are used; reloading the page always starts a fresh game.
  • Puzzle requests: when you start a new game, your browser calls our server function /api/puzzle. As with any request on the internet, the server receives the technically required connection data (IP address, timestamp, user agent). The IP address is used to deliver the response, to limit excessive requests (rate limit, kept briefly in memory) and to defend against abuse, and is not combined with other data. Suspicious, abusive requests (for example exceeding the rate limit) are logged briefly in the host's server logs for follow-up; the affected IP may be used to permanently block abusive sources.

Processing of connection data is necessary to deliver the website and to keep it secure (Art. 6(1)(f) GDPR – legitimate interest in safe operation). Because no data is stored in the browser, no consent is required for this.
