How to play

Select an empty cell and type a digit. Correct entries stay black, wrong ones are marked in red as soon as you enable the check option.

Use notes mode to write small candidates into a cell. Press the notes button or the N key to switch modes.

Stuck? The hint button reveals a single cell. Undo and redo let you take moves back.

When every row, column and box contains the digits 1 to 9, the puzzle is solved. Your time, mistakes and hints end up in your personal statistics.

Sudoku strategies for beginners

  • Scan first: look for rows, columns and boxes that already contain eight digits.
  • Look for hidden singles: inside a box, check which digit has only one possible cell left.
  • Work box by box and use the highlighting to see which digits are already used.
  • Note candidates instead of guessing - cross-hatching is faster than trial and error.
  • If you are truly stuck, stop the clock, take a break and come back with fresh eyes.

Frequently asked questions

Is the game free?

Yes. All difficulty levels are free, without registration and without advertising.

Can I play on my phone?

Yes, the board adapts to any screen size. You can also add the page to your home screen and use it like an app.

Where do the puzzles come from?

Puzzles are provided by the YouDoSudoku API and rated by this app using human solving techniques. If the API is unavailable, a puzzle is generated directly in your browser.
